# Assignment 15: Linked List (`15-linkedlist.md`)

This directory contains standalone Java solution files for all core Linked List problems in Assignment 15 (`15-linkedlist.md`) from Kunal Kushwaha's Data Structures & Algorithms Bootcamp.

## Included Solution Files

1. `ListNode.java` - Standard Singly-Linked List Node definition.
2. `CustomLinkedList.java` - Complete Singly Linked List implementation with insertion, deletion, and traversal methods.
3. `ReverseLinkedList.java` (LeetCode 206) - Iterative and recursive linked list reversal.
4. `MiddleOfLinkedList.java` (LeetCode 876) - Finding the middle node using fast and slow pointers.
5. `LinkedListCycle.java` (LeetCode 141 & 142) - Cycle detection, cycle length calculation, and start node identification.
6. `MergeTwoSortedLists.java` (LeetCode 21) - Merging two sorted linked lists in $O(N+M)$ time.
7. `PalindromeLinkedList.java` (LeetCode 234) - Checking if a linked list is a palindrome in $O(N)$ time and $O(1)$ space.
8. `ReorderList.java` (LeetCode 143) - In-place reordering of linked list nodes ($L_0 \to L_n \to L_1 \to L_{n-1} \dots$).
9. `RemoveDuplicatesSorted.java` (LeetCode 83) - Deleting duplicates from a sorted linked list.
10. `ReverseNodesKGroup.java` (LeetCode 25) - Reversing nodes in groups of $k$.
