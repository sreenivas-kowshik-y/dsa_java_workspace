# Assignment 14: Object-Oriented Programming (`14-oop.md`)

This directory contains individual Java program files for all core Object-Oriented Programming topics in Assignment 14 (`14-oop.md`) from Kunal Kushwaha's Data Structures & Algorithms Bootcamp.

## Included Solution Files

1. `ClassesAndObjects.java` - Class definitions, object instantiation, default & parameterized constructors, and `this` reference.
2. `InheritanceDemo.java` - Single, multilevel, and hierarchical inheritance using `super`.
3. `PolymorphismDemo.java` - Method overloading (compile-time) and overriding (runtime) with dynamic method dispatch.
4. `EncapsulationAndAbstraction.java` - Access modifiers (`private`, `protected`, `public`), getters/setters, and abstract classes.
5. `InterfacesDemo.java` - Interface design, multiple interface implementation, and contract enforcement.
6. `GenericsDemo.java` - Type-safe generic classes and custom generic collection data structures.
