# Assignment 11: Bitwise Manipulation (`11-bitwise.md`)

This directory contains standalone Java program files covering all bitwise operator questions and LeetCode problems in `11-bitwise.md` from Kunal Kushwaha's Data Structures & Algorithms Bootcamp.

## Included Files

1. `OddEven.java` - Check if number is odd or even using bitwise AND (`&`).
2. `SingleNumber.java` (LeetCode 136) - Find the non-repeating number using XOR (`^`).
3. `FindIthBit.java` - Get the value of the i-th bit.
4. `SetIthBit.java` - Set the i-th bit to 1.
5. `ResetIthBit.java` - Reset (clear) the i-th bit to 0.
6. `RightmostSetBit.java` - Position of the rightmost set bit.
7. `PowerOfTwo.java` (LeetCode 231) - Check if number is power of two via `(n & (n - 1)) == 0`.
8. `CalculatePower.java` - Calculate $a^b$ using bitwise fast exponentiation.
9. `CountSetBits.java` (LeetCode 191) - Count total 1-bits using Brian Kernighan's algorithm.
10. `XORRange.java` - Compute XOR from $0$ to $N$ and range $A$ to $B$ in $O(1)$.
11. `FlippingAnImage.java` (LeetCode 832) - Flip array horizontally and invert bits.
12. `NumberToHexadecimal.java` (LeetCode 405) - Convert integer to hexadecimal representation.
13. `CountingBits.java` (LeetCode 338) - Count set bits for all numbers from $0$ to $N$.
