# Assignment 16: Stack & Queue (`16-stack-queue.md`)

This directory contains standalone Java solution files for all core Stack and Queue problems in Assignment 16 (`16-stack-queue.md`) from Kunal Kushwaha's Data Structures & Algorithms Bootcamp.

## Included Solution Files

1. `CustomStack.java` - Array implementation of Stack data structure.
2. `CustomQueue.java` - Array implementation of Queue data structure.
3. `CircularQueue.java` - Efficient Circular Queue with $O(1)$ push and pop operations.
4. `QueueUsingStack.java` (LeetCode 232) - Implement Queue using two Stacks.
5. `ValidParentheses.java` (LeetCode 20) - Balance checking for brackets.
6. `MinAddToMakeValid.java` (LeetCode 921) - Count minimum parentheses additions.
7. `MinimumInsertionsParentheses.java` (LeetCode 1541) - Insertions to balance parentheses.
8. `LargestRectangleInHistogram.java` (LeetCode 84) - Monotonic Stack algorithm for maximum histogram area.
9. `SlidingWindowMaximum.java` (LeetCode 239) - Monotonic Deque algorithm for window maximums.
10. `TwoStacksInArray.java` - Space-efficient implementation of two stacks in one array.
