# Assignment 12: Mathematics for DSA (`12-math.md`)

This directory contains individual Java program files for all problems in `12-math.md` from Kunal Kushwaha's Data Structures & Algorithms Bootcamp.

## Included Files

1. `PrimeCheck.java` - Basic prime checking algorithm ($O(\sqrt{N})$).
2. `SieveOfEratosthenes.java` (LeetCode 204) - Prime generation up to $N$.
3. `SquareRootBinarySearch.java` - Square root calculation using Binary Search with floating-point precision.
4. `NewtonRaphsonSqrt.java` - Square root approximation using Newton-Raphson formula.
5. `FactorsOfNumber.java` - Finding factors of a number sorted in $O(\sqrt{N})$.
6. `GCDandLCM.java` - Euclidean Algorithm for HCF/GCD and LCM.
7. `AddBinary.java` (LeetCode 67) - Adding two binary string values.
8. `ExcelSheetColumnNumber.java` (LeetCode 171) - Convert column title to number.
9. `HappyNumber.java` (LeetCode 202) - Floyd's Cycle Detection for Happy Numbers.
10. `SelfDividingNumbers.java` (LeetCode 728) - Check self-dividing range.
