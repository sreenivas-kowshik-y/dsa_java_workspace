# Assignment 17: Trees (`17-trees.md`)

This directory contains standalone Java solution files for all core Binary Trees and Binary Search Trees questions in Assignment 17 (`17-trees.md`) from Kunal Kushwaha's Data Structures & Algorithms Bootcamp.

## Included Solution Files

1. `TreeNode.java` - Definition for a binary tree node.
2. `BinaryTreeTraversals.java` (LeetCode 144, 94, 145) - Preorder, Inorder, and Postorder Traversals.
3. `LevelOrderTraversal.java` (LeetCode 102) - Breadth-First Search (BFS) level order traversal.
4. `ZigzagLevelOrderTraversal.java` (LeetCode 103) - Alternating level order traversal using Deque.
5. `PopulatingNextRightPointers.java` (LeetCode 116) - $O(1)$ auxiliary space level-linking in perfect binary trees.
6. `LowestCommonAncestorBinaryTree.java` (LeetCode 236) - Finding lowest common ancestor using recursion.
7. `KthSmallestElementBST.java` (LeetCode 230) - Inorder stack traversal to find the $k$-th smallest element in BST.
8. `SerializeAndDeserializeBinaryTree.java` (LeetCode 297) - Preorder serialization and deserialization.
9. `PathSum.java` (LeetCode 112) - Checking root-to-leaf paths matching target sum.
10. `FlattenBinaryTreeToLinkedList.java` (LeetCode 114) - In-place flattening of binary tree using Morris-style pointer manipulation.
