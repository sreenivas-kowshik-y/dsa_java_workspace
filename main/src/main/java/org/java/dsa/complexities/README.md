# Assignment 13: Time & Space Complexities (`13-complexities.md`)

This directory contains Java programs and comprehensive theoretical breakdowns for Assignment 13 (`13-complexities.md`) from Kunal Kushwaha's Data Structures & Algorithms Bootcamp.

## Included Solution Files

1. `TimeComplexityOverview.java` - Code examples demonstrating $O(1)$, $O(\log N)$, $O(N)$, $O(N \log N)$, and $O(N^2)$ algorithms.
2. `SpaceComplexityOverview.java` - Demonstrating auxiliary space ($O(1)$ vs $O(N)$) and recursion stack space.
3. `RecurrenceRelations.java` - Implementation and recurrence analysis ($T(N) = T(N/2) + O(1)$, $T(N) = 2T(N/2) + O(N)$, $T(N) = 2T(N-1) + O(1)$).

## Key Asymptotic Notations
- **Big-O ($O$)**: Upper bound (Worst-case complexity).
- **Big-Omega ($\Omega$)**: Lower bound (Best-case complexity).
- **Big-Theta ($\Theta$)**: Tight bound (Average/Exact growth rate).
